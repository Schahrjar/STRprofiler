# STRprofiler
A method for reliable profiling of genomic short tandem repeat loci from sequence data.

## Scripts description
Below is a breif on the functionality of each of the scripts embeded in STRprofiler.

### STR-catalogue_cleanup.sh
This script provides major steps for creating a STRs catalogue for reliable genotyping

### permutation-scanner.py
This tool finds sequence motifs that are molecularly the same regarding the cyclic rotation or reverse complement of the DNA sequence - but their sequence motif may not be shown the same due to the reference genome consensus.

### EH_genotype-analyser.R
This script aggregates allelic repeat lengths from VCF files generated by ExpansionHunter.

### unmapped_STRs.sh
This is to find novel STR loci absent from the hg38 reference genome assembly, by screening unmapped sequence read from mapped sequence data (BAM files) and aligning them to the T2T-CHM13 (hs1) genome assembly.

## Supporting files
Two directories are available in this repository: variant-catalogue and outputs. The former provides the BED and JSON formats of the STR catalogue that created for the main study (see Citation below), and the later includes the summary statistics TSV file of STRs profile produced in the main study.
